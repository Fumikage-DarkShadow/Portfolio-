## À propos de ce repo

Ce repo héberge mon **portfolio personnel** déployé via GitHub Pages.
Site one-page développé en HTML/CSS/JS vanilla — pas de framework, pas de build, juste du code propre.

L'idée : montrer en un coup d'œil **qui je suis, ce que je fais, et où je vais**.

## Quelques projets que j'ai bien aimé faire

🔬 **[Custom RAT](assets/pdf/rapport-custom-rat.pdf)** — Développement complet d'un Remote Access Trojan en lab isolé. Agent C/C++17 (keylogger, screenshot, persistance) + serveur C2 Python avec TLS 1.3. Approche Red Team / Blue Team pour mieux comprendre les menaces qu'on cherche à détecter.

🦠 **[Analyse Statique du Ransomware Satan](assets/pdf/analyse-statique-satan.pdf)** — Inspection complète du malware sans l'exécuter. HxD pour le binaire, PE Studio pour les imports, VirusTotal pour la détection multi-moteurs. Comprendre la menace avant qu'elle frappe.

🎯 **[Pentest & Phishing par site cloné](assets/pdf/rapport-pentest-phishing.pdf)** — Audit offensif sous Kali Linux : 10 modules (Nmap, Metasploit, SQLmap, Burp Suite...) et simulation d'une campagne de phishing via SET. La meilleure défense passe par comprendre l'attaque.

📱 **[Floww](assets/floww-preview.html)** — Application mobile de gestion de budget pour la Gen Z. React Native + Expo, dashboard avec Flow Score, suivi des abonnements. Parce que la tech, c'est pas que de la cyber.
